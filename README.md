# Love Chloe website

## Editing
Sign in at https://app.pagescms.org/ and select this repository. Open **Website content and images**, make changes and save. Upload images through the image fields.

## Cloudflare deployment
Create a **new** Cloudflare Pages project connected to this GitHub repository. Framework preset: None. Build command: leave blank. Build output directory: `/` (repository root). Deploy to the generated pages.dev address and test before moving lovechloe.co.uk from the old Direct Upload project.

## Enquiries
The form submits to Web3Forms. Test delivery and WhatsApp contact preference after deployment. The customer remains on the page. Mobile number is optional. Do not publish personal customer data in the repository.
